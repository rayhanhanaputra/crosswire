SimLab: the Testbed You Can See

Six deterministic digital twins with an agent in each: a smart farm, a water plant, a warehouse fleet, hospital climate, a smart building and a command drill. No model, no physical output.

Send the same payload Crosswire sends. Under the basic profile the valve opens and the twin shows it; under validated the content is kept as data.

Each control change is reported to the Crosswire sink as executed or refused, with the trial's nonce and session, so the workbench scores it like any target.

A stage prop that decides "compromised" with a few regular expressions. It shows the effect; the numbers in this talk come from the reference agents.

SimLab is for the room: people see a valve open. Say in the same breath that it is not a measurement target. Its job in the submission is the demo and a free, reproducible end-to-end check of the sink contract.
