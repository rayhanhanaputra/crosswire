Crosswire: one binary, Repeater and Intruder for perception paths

Real artifacts

QR and sign PNGs, rendered invoices, speech and tone WAVs, Morse timelines to the serial rig. Each decoded back where a decoder exists. A text-only channel is labelled modeled everywhere.

Verdicts from trials

Three arms, a nonce per trial, a sink for executed tools, Wilson intervals. Five outcomes; never a bare tick.

Run bundles

A zip of run.json, artifacts, sink events and hashes. A knowledge-base entry can say “reproduced” only by citing one; the registry check enforces it.

Go, no cgo, builds for macOS, Windows and Linux. Embedded web UI on loopback. Four reference targets ship in the same binary.
