Two Ways to Decide Who May Act

By the request path

Which endpoint, which turn, which tools are offered there. Input classifiers, tool withholding, turn-level confirmation. Cheap, and what deployed layer lists mostly contain.

By the value's provenance

Where did this account, this address, this door name come from? A record check, a taint check, a confirmation that shows the argument's source.

Path-keyed layers assume content is consumed on the request that delivered it. Memory, handoff notes and inboxes break that. Prediction: every store-then-trigger channel turns them off; a provenance check holds, at a utility cost we can measure.
