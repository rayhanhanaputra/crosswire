Measure Your Own Agent This Afternoon

1. Point your agent's tools at a URL you own, or add one line that posts each call there.

2. Pick the privileged tool you care about and the input the agent reads that you did not write.

3. Send the instruction thirty times through that input, thirty benign controls, thirty typed into chat.

4. Count hits at the sink with the nonce. Report k of N with the interval. Publish the rows that went against you.

This is the ask. Crosswire does it in one binary, but the method needs no tool: a nonce, a URL and a control arm.
