What a Run Leaves Behind

run.json

every trial, arm, wording, nonce, request, reply, verdict

artifacts/

the PNG, WAV and PDF bytes that were sent, with hashes

sink.json

every tool call, executed or refused, with the reason and the session

summary.json

k of N per arm with intervals, the target's build and layers

A claim in the knowledge base is "reproduced" only by citing one of these. Every number in this deck has one.

The bundle is what makes the result arguable. If someone disagrees with a row, they can open the trial and read the reply.
