Channels that cannot carry an instruction

Morse over an LED

A six-letter word at 12 words per minute is 23 pulses over about 4.6 seconds; the shortest element is 100 ms.

A vision agent sampling about one frame per second sees at most five frames of it. The earlier project sent the decoded text to the target and skipped the only physical step.

Kept as an adapter that drives the real rig, so the negative result can be re-measured against a fast light sensor.

DTMF tones

Sixteen symbols: 0 to 9, star, hash, A to D. No encoding of language exists.

What remains is narrow and real: where an agent maps key presses to actions, tones trigger the action and a speech guardrail never hears them.

The reference voice agent detects a tone clip with a Goertzel bank before it tries speech recognition.

Also removed from the claim: numeric sensor values (a number carries no instruction), binary toggles, and inter-agent notes, which are text and belong to the existing text-injection tools.

Reviewers trust a project that kills its own channels. The old eight-by-six grid of channels looked like coverage; most cells were labels on a JSON key.
