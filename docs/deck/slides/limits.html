LimitConsequence

Reference targets, not productsThe agents were written for this project to be realistic, not to represent any vendor. No product was tested.

Hardened was not attacked furtherData-flow attacks that need no tool control were out of scope. “Not observed” bounds the rate; it does not clear the design.
