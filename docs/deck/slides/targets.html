Real tool-calling agents on gpt-4o-mini and deepseek-flash, written for this project. Not products. Eight builds each.

Six agents, each a real model with real tools. The red line under each is the privileged action we count. Desk is the memory channel: the note does nothing when it arrives and everything on the next routine request. Eight builds per agent: plain, the classifier on chat, on perception, hardened, and hardened with one of its four layers off. The builds differ in architecture, not in a keyword filter: the earlier demo target decided "compromised" with eight regular expressions, which taught the wrong lesson.
