Defenses

Four layers, each with an off switch. Where the classifier sits is a flag.

User chat

the only trusted turn

Sensor

name, audio, frame, file

1 Quarantine

no tools, fixed schema

Classifier

on chat, on perception, or both

2 Withhold, 3 Confirm

privileged tools off the perception path; a call needs a flag only the user turn sets

4 Interlock

a check in code

sets the confirm flag

free text stops here

account must match the ticket or the vendor record; refusals go to the sink

Four layers, each a flag on the reference target, so the audience can read the code and switch one off. One: a tool-less model extracts a fixed structure, so the privileged model never sees free text from a sensor. Two: on the perception path the privileged tools are not even offered, and a call to one is refused and recorded. Three: unlocking, disarming, paying and sending need a flag only a user turn can set. Four: the handler checks the account against the ticket or the vendor record, whatever the model asked. The classifier is separate: it is the same code wherever it sits, and the flag says where. End on the method: the ask is that people measure, not that they trust this deck.
