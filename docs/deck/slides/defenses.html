Four moves, each measured together as the hardened reference target, so the audience can read the code. One: a tool-less model extracts a fixed structure, so the privileged model never sees free text from a sensor. Two: the guardrail inspects the representation the model acts on, the schema and the chat, not the raw sensor. Three: unlocking, disarming, paying and sending need a flag only a user turn can set. Four: the account must match the vendor record in the tool handler, whatever the model asked. End on the method: the ask is that people measure, not that they trust this deck.
