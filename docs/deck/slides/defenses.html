For defenders: move four things

The guardrail, after perception

Inspect the representation the model acts on: the transcript, the extracted text, the entity block. A filter on the chat box inspects a path the attacker does not use.

Perceived content, into a schema

A tool-less model extracts a fixed structure; the privileged model never sees free text from a sensor, a document or a device name.

Confirmation, onto the user channel

Unlocking, disarming, paying and sending need a flag that only a user turn can set. Nothing perceived can confirm itself.

Interlocks, into code

Account must match the vendor record; fill time has a cap; the alarm needs a code. Enforced in the tool handler, whatever the model asked.

Measured together as the hardened policy: 0 of 10 on every scenario with the payload still delivered. Test your own agent the same way: three arms, a control, repeats, and a sink you own.

These four are the hardened reference target, so the audience can read the code. End on the method: the ask is that people measure, not that they trust this deck.
