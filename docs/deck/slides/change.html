What to Change in Your Agent

Move the classifier. Run it on what the model is about to read, not only on what the user typed.

Put the checks in code. Account matches the record, door matches the request, recipient is on the list. The model does not get a vote.

Separate perception from action. A tool-less model extracts a schema; the model with tools never sees free text from a sensor.

Measure it. Nonce, sink, control, thirty trials. Then switch each layer off and see which one you were relying on.

Four concrete changes, each backed by a row in the tables. The last one is the real ask: the other three are only as good as the measurement that checks them.
